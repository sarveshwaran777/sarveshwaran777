## 📁 Featured Projects

### 💬 FloatChat
AI-powered chatbot designed for querying and visualizing ARGO ocean data. Integrates LLMs to let researchers explore oceanic trends and vertical profiles easily.
*   **Tech Stack:** Python, FastAPI, React
*   [View Project →](https://github.com/sarveshwaran777/FloatChat)

### 🛡️ AI Supply Chain Guardian
An intelligent demand forecasting and risk mitigation platform for MSMEs. Employs predictive modeling to optimize inventory levels and safeguard supply chains.
*   **Tech Stack:** Python, Flask, PostgreSQL
*   [View Project →](https://github.com/sarveshwaran777/AI-Supply-Chain-Guardian)

### 🏭 FactoryOps AI
An AI assistant tailored for manufacturing operations, utilizing telemetry feeds from assembly lines to perform real-time anomaly detection and predictive maintenance.
*   **Tech Stack:** FastAPI, React, SQLite
*   [View Project →](https://github.com/sarveshwaran777/FactoryOps-AI)

### 🧹 DUSTRIX CleanBot Pro
An autonomous smart floor-cleaning robot. Features microcontrollers programmed for sensor integration, obstacle avoidance, and path optimization.
*   **Tech Stack:** C, Arduino, Firebase
*   [View Project →](https://github.com/sarveshwaran777/DUSTRIX-CleanBot-Pro)

### 🚨 Smart Emergency Response System
An IoT-enabled platform connecting sensor nodes across industrial environments to detect emergencies (gas leaks, fires) and automate alert dispatches.
*   **Tech Stack:** Python, Arduino, Firebase
*   [View Project →](https://github.com/sarveshwaran777/Smart-Emergency-Response-System)

### ⚡ Power Quality Monitoring System
A smart telemetry system that monitors real-time voltage, current, and power factor parameters to identify grid faults and optimize energy efficiency.
*   **Tech Stack:** C, React, Arduino
*   [View Project →](https://github.com/sarveshwaran777/Power-Quality-Monitoring-System)
